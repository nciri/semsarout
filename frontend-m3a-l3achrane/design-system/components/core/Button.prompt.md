Primary action button; navy by default, one gold `accent` per view for the top action.

```jsx
<Button variant="accent" iconLeft="user-plus">S'inscrire</Button>
<Button variant="secondary">Je suis salarié</Button>
```
Variants: primary · accent · secondary · ghost · danger. Sizes sm/md/lg. Darkens on hover, scales 0.98 on press.
