# Seeker app UI kit (`apps/web` authenticated space)

- **Dashboard** — navy `SidebarNav`, greeting header with verified avatar, three stat cards
  (verified profile / avg compatibility / applications), recommendation grid of `ListingCard`s,
  recent activity + next-step panels.
- **Messaging** — conversation list with online dots and unread markers, live chat thread with
  navy sent / white received bubbles, composer (type + Enter to send). Admin thread uses the
  brand mark instead of an avatar.

Click **Messagerie** in the sidebar to switch views. Files: `index.html`, `App.jsx`.
