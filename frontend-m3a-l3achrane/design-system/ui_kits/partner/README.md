# Partner portal UI kit (`apps/partner`)

The institutional B2B portal (universities / employers). Navy sidebar scoped to the partner
context (active convention chip), partner-specific nav (Affiliés, Vérifications, Offres réservées,
Subventions, Reporting, Facturation, API & webhooks).

Dashboard shows the four headline metrics from the brief (affiliates registered, housing rate,
median matching delay, median budget), the **k-anonymity / anonymized-reporting** notice, and the
pseudonymized affiliate roster table (external id hashes, promotion, status badges) — **never**
addresses or roommate identities, per the confidentiality invariant.

Files: `index.html`, `App.jsx`.
